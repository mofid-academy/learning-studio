# ارائهٔ HTML مفید آکادمی

قالب Tooplate 2147 Titan Folio جای قالب Orbital را گرفته است. هویت آموزشی، رنگ‌های مفید آکادمی و فونت Pinar VF در آن اعمال شده‌اند. عکس‌ها و متن‌های نمونهٔ پورتفولیوی قالب به محتوای آموزشی وارد نمی‌شوند.

تب ارائه، همان HTML خروجی را در iframe دارای sandbox نمایش می‌دهد. پیمایش اسلاید در iframe شمارهٔ اسلاید انتخاب‌شدهٔ ویرایشگر را با پیام کنترل‌شده همگام می‌کند. نودهای ساخت دوره و API ورود/انتشار تغییر نکرده‌اند. دانلود HTML و PowerPoint و ویرایش اسلاید محفوظ‌اند.

HTML شامل CSS، اسکریپت و فونت است و بدون اینترنت کار می‌کند. تصاویر فقط از منابع دوره و data URL معتبر خوانده می‌شوند. قالب در همان خروجی حالت روشن/تاریک، توقف حرکت، تمام‌صفحه و چاپ/PDF دارد. دادهٔ حساب و توکن داخل فایل ارائه قرار نمی‌گیرد.

اعتبار قالب: https://www.tooplate.com/view/2147-titan-folio

بررسی syntax اسکریپت ترکیبی سایت، HTML آفلاین، فونت، escape متن، مجوزهای sandbox و کنترل فرستندهٔ پیام انجام شد. در محیط اجرا مرورگر نصب نیست و بررسی بصری انجام نشده است.
