# ارائهٔ آموزشی مفید آکادمی

نمایشگر ارائه با رنگ‌های سبز و فیروزه‌ای مفید و فونت متغیر Pinar VF ساخته شده است. محتوای ارائه از همان اسلایدها، فصل‌ها، یادداشت‌ها، منابع و تصاویر دوره خوانده می‌شود. این قالب هیچ دورهٔ نمونه‌ای را جای دادهٔ دوره نمی‌گذارد.

قالب جدید در `teaching-presentation.js` قرار دارد. فایل `index.html` آن را پیش از اجرای برنامه بارگذاری می‌کند و فقط خروجی تابع `mofidOrbitalHTML` را از مسیر `MofidTeachingPresentation.upgrade` عبور می‌دهد. بدنهٔ سازندهٔ قبلی با نام `mofidOriginalPresentationHTML` محفوظ است؛ اگر فایل جدید در دسترس نباشد یا تبدیل خطا بدهد، همان خروجی قبلی استفاده می‌شود. چهل فایل اصلی `chunks/v2-*.txt` تغییر نکرده‌اند.

این جایگزینی فقط داخل نمایشگر ارائه و خروجی دانلود HTML اعمال می‌شود؛ ظاهر بیرونی پنل ادمین و پنل کاربران، مسیرهای ورود، انتشار دوره، ذخیرهٔ پیشرفت، آزمون و دانلود PowerPoint دست‌نخورده‌اند. ادمین و کاربر قالب ارائهٔ یکسانی می‌بینند. iframe همان sandbox قبلی (`allow-scripts allow-modals allow-downloads`) و اجازهٔ تمام‌صفحه را دارد؛ `allow-same-origin` اضافه نشده است.

اسلایدها با حرکت جهت‌دار کوتاه جابه‌جا می‌شوند. در «حالت تدریس»، نکته‌ها و تصاویر مرحله‌به‌مرحله ظاهر می‌شوند؛ انتخاب این حالت و جای هر اسلاید تا زمانی که نمایشگر باز است حفظ می‌شود. توقف حرکت و ترجیح کاهش حرکت سیستم رعایت می‌شوند. کلیدهای جهت، PageUp/PageDown، فاصله، Home/End و ورق‌زدن لمسی در دسترس‌اند.

بارگذاری تصاویر و چاپ از همان پیام‌های محدود میان iframe و برنامهٔ میزبان استفاده می‌کند و فرستندهٔ پیام بررسی می‌شود. فایل ارائه شامل فونت و CSS و اسکریپت است و حساب، توکن ورود یا مسیر API جدیدی به آن اضافه نمی‌شود. چاپ/PDF همهٔ نکته‌ها و یادداشت‌ها را نمایش می‌دهد و پس از پایان چاپ، وضعیت قبلی یادداشت‌ها برمی‌گردد.

`presentation-preview.html` نمونهٔ عمومیِ ازقبل‌موجود برای بررسی ظاهر و کنترل‌های همین قالب است؛ داده‌های یک حساب وارد آن نمی‌شوند.

بررسی‌های انجام‌شده: حفظ همهٔ articleهای یک دورهٔ ۵۵ اسلایدی، escape متن، تصاویر و منابع؛ همگامی شمارهٔ اسلاید با میزبان؛ ورق‌زدن سریع؛ نمایش مرحله‌ای؛ کاهش حرکت؛ کنترل فرستندهٔ پیام؛ چاپ و بازیابی وضعیت یادداشت‌ها؛ حفظ برنامهٔ ورود، مدیریت و آزمون.
