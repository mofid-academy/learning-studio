# ارائهٔ HTML مفید آکادمی

قالب Orbital 2167 از Tooplate برای فهرست فصل‌ها شخصی‌سازی شده است. CSS و JavaScript داخل خروجی HTML قرار می‌گیرند و تصاویر فقط از منابع دوره، با data URL معتبر، وارد می‌شوند. عکس‌های نمایشی قالب به‌عنوان تصویر آموزشی استفاده نمی‌شوند.

در تب ارائه، «دانلود ارائه HTML» را انتخاب کنید و فایل را در مرورگر باز کنید. دکمه‌های فصل، اسلاید، تمام‌صفحه، توقف حرکت و چاپ/PDF در فایل در دسترس‌اند. خروجی آفلاین است؛ فارسی با فونت‌های سیستم نمایش داده می‌شود.

در ساخت دوره‌های جدید، درخواست presentation توضیحات مستند بیشتری می‌خواهد و اسلایدها عنوان بخش و یادداشت تفصیلی دارند. دوره‌های قبلی و ویرایش اسلایدهای آنها حفظ می‌شوند. طرح جدید مربوط به خروجی HTML است؛ خروجی PowerPoint و منطق ورود/انتشار تغییر نکرده‌اند. HTML محدود به داده‌های موجود دوره است و تصویر جدیدی از فایل استخراج نمی‌کند.

برای داشتن این تغییر در محتوای دوره‌های مشترک، دورهٔ جدید را پس از ساخت منتشر کنید. پس از ثبت پاسخ شرکت‌کننده، تغییر محتوای همان دوره نیازمند شناسهٔ جدید است.

اعتبار قالب: https://www.tooplate.com/view/2167-orbital
شرایط استفاده: https://www.tooplate.com/about

بررسی‌ها: syntax کل اسکریپت‌های سایت، RTL، آفلاین بودن HTML، escape متن، رد URL تصویر نامعتبر، تکرار نشدن تصاویر و تست منطق سرور پنل موفق بود. در این محیط مرورگر نصب نیست؛ بررسی تصویری در مرورگر انجام نشده است.
