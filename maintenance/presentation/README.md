# ارائهٔ آموزشی مفید آکادمی

نمایشگر ارائه از رنگ‌های سبز و فیروزه‌ای مفید و فونت متغیر Pinar VF استفاده می‌کند. متن و عنوان‌ها نسبت به نسخهٔ اول کوچک‌ترند. صحنه در ارتفاع پنجره قرار می‌گیرد؛ نوار ابزار ثابت می‌ماند و فقط محتوای اسلاید، در صورت نیاز، اسکرول می‌شود.

ارائهٔ پیش‌فرض خلاصه است: حداکثر ۱۲ اسلاید، شامل عنوان، حداکثر ۱۰ بخش آموزشی و جمع‌بندی. برای دورهٔ ۸ فصلی، ۱۰ اسلاید ساخته می‌شود. هر اسلاید حداکثر ۳ نکتهٔ کوتاه دارد. این خلاصه استخراجی از نکات کلیدی فصل‌ها و در صورت نبود آن‌ها، نکته‌های اسلایدهای موجود است؛ عنوان‌ها و ترتیب فصل‌ها حفظ می‌شوند و فصل‌های زیاد به ترتیب کنار هم قرار می‌گیرند. متن بلند در مرز واژه با علامت «…» کوتاه می‌شود. هیچ سرویس یا مدل جدیدی فراخوانی نمی‌شود؛ لازم است مدرس در صورت نیاز محتوای ارائه را بازبینی کند.

جزوه، درس‌ها، منابع، سؤال‌ها، فلش‌کارت‌ها و پیشرفت ذخیره‌شده تغییر نمی‌کنند. خلاصه تا قبل از ذخیرهٔ ویرایش توسط ادمین فقط برای نمایش و خروجی ساخته می‌شود. اگر ادمین یک اسلایدِ خلاصه را ویرایش و ذخیره کند، همان مجموعهٔ کوتاه از مسیر معمول ویرایش اسلایدهای برنامه ذخیره می‌شود؛ محتوای درسی همچنان کامل می‌ماند. ارائه‌های ازقبل‌کوتاه (۱۲ اسلاید یا کمتر) تعداد و ترتیب خود را حفظ می‌کنند.

`teaching-presentation.js` رابط `MofidTeachingPresentation` را عرضه می‌کند: `compact` برای دادهٔ کوتاه، `upgrade` برای HTML نمایشگر و `attachFrame` / `enterPresentation` / `leavePresentation` برای تمام‌صفحه. فایل `index.html` آن را هم‌زمان پیش از برنامه می‌خواند و ۷ جایگزینی محدود در سازندهٔ HTML، پنل ارائه، شمارندهٔ تعداد اسلاید، خروجی PowerPoint و اتصال iframe اعمال می‌کند. چهل فایل اصلی `chunks/v2-*.txt` تغییر نکرده‌اند. بارگذاری یا تبدیل ناموفق به سازندهٔ قبلی برمی‌گردد. ظاهر بیرونی پنل ادمین، ورود، درس‌ها و آزمون همان است.

تمام‌صفحه از دکمهٔ داخل نمایشگر یا «ارائه تمام‌صفحه» بیرون آن اجرا می‌شود. میزبان iframe را بدون جابه‌جایی یا بارگذاری مجدد بزرگ می‌کند و در صورت پشتیبانی، Fullscreen API را نیز فراخوانی می‌کند. اگر مرورگر اجازه ندهد، ارائه تمام پنجره را می‌پوشاند. دکمهٔ خروج یا Escape، نمای معمول و استایل‌های قبلی را بازمی‌گرداند؛ شمارهٔ اسلاید و مرحلهٔ تدریس حفظ می‌شوند. پیام‌ها فقط از contentWindow همان iframe پذیرفته می‌شوند و هنگام خروج از پنل listenerها پاک می‌شوند. sandbox قبلی `allow-scripts allow-modals allow-downloads` با اجازهٔ fullscreen حفظ شده است؛ دسترسی هم‌مبدأ اضافه نشده است.

نمایش، دانلود HTML و PowerPoint همگی از نسخهٔ کوتاه استفاده می‌کنند. سازندهٔ PowerPoint و مسیر دانلود و ذخیرهٔ آن دست‌نخورده‌اند؛ فقط دادهٔ اسلاید خلاصه به آن داده می‌شود. یادداشت‌ها و منابع هر اسلاید موجودند. نمایش مرحله‌ای، حرکت جهت‌دار، ترجیح کاهش حرکت، لمس و کلیدهای صفحه حفظ شده‌اند. فقط اولین تصویر هر اسلاید در نمای صفحه دیده می‌شود؛ چاپ تصاویر و یادداشت‌ها را نمایش می‌دهد. تصاویر از همان پیام‌های محدود و تأییدشدهٔ قبلی بارگذاری می‌شوند.

`presentation-preview.html` همان نمونهٔ عمومیِ ازقبل‌موجود با دو اسلاید است که اکنون در iframe با همان sandbox برنامه و اتصال تمام‌صفحه نمایش داده می‌شود. هیچ دوره یا حساب خصوصی در آن قرار نمی‌گیرد. فایل HTML قابل دانلود، فونت و CSS و اسکریپت خود را همراه دارد.

اعتبار قالب قبلی Titan که برای بازگشت سازگار در بستهٔ اصلی حفظ شده است: https://www.tooplate.com/view/2147-titan-folio

عبارت توضیحی بالای ارائه و ردیف طولانی منابع زیر اسلایدها از نمای وب و دانلود HTML حذف شده‌اند؛ شناسه‌ها و داده‌های منابع در دوره حفظ می‌شوند. شعار قدیمی «یادگیری امروز، توانمندی فردا» در بستهٔ فعلی برنامه وجود ندارد؛ نسخهٔ درخواست چهل فایل منبع به‌روزرسانی شده است تا نسخهٔ قدیمی از حافظهٔ مرورگر خوانده نشود.
